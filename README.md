# NeonSpin — лендинг игровой платформы

Статический одностраничный сайт (HTML + CSS + немного JS, без сборки и зависимостей).

Открыть: `index.html` в браузере.

Содержит: шапку с кнопками входа/регистрации, промо-баннеры, плитки разделов, карусель игр, футер с ссылками, платежными методами и плашкой 18+.

Все игры, провайдеры, бонусы и логотип здесь условные. Перед использованием замените название, тексты, ссылки и реальные ассеты на свои и проверьте требования лицензии и законодательства для азартных сервисов.
